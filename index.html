Tips: 

Hover over text to read descriptions.

Blacklist rows that have unrelated info, 
or do not need to be crosschecked.

Whitelist rows that need specific checking.

Click on the links in the output to go to the corresponding
cell position in the table.

Click on the output items to highlight or bookmark
important errors.






Troubleshooting:

[ Files do not open properly. ]
Ensure the file format is .xlsx OR .csv
Remove export headers, export trailers,
and other extraneous data.



[ Nothing is displayed in the output. ]
Double check that only relevant rows are included.
If not, delete ALL irrelevant rows from each spreadsheet.
Double check that all rows are in the same order.
If not, sort all spreadsheets by the same columns in excel.
You may need to use a multi-layered sort if there is no
unqiue identifier column to sort by. (ID Column)

If you are still having issues:
If all columns you need cross checked
are correctly matched in the output,
The matched columns have no format errors or inconsistencies.
If the columns you need cross checked 
are not matched together,
Try increasing the Error Tolerance.



[ Too much is displayed in the output. ]
Click on the column headers to blacklist 
unwanted column matches.
OR
Select "Whitelist" from the dropdown in the top
menu and select only the columns you want cross checked.
OR
Decrease the Error Tolerance






Limitations:

May, in certain cases mark correct data as mismatched 
due to extraneous column matching.

Spreadsheets should have at least 20 rows.
This is a soft limit, but the program may not function
as expected with very small amounts of data.

The auto checking algorithm can only cross check rows
that are in order. The program will detect row shifts and 
output a red warning if it has found one, however the first 
10 rows must be in the correct order for it to detect 
row shifts.

If the first 10 rows are not in the correct order,
no checks may run at all.
